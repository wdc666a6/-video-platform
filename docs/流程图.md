# 视频平台项目流程图

---

## 项目整体功能结构

### 前台用户模块

| 功能 | 说明 |
|------|------|
| 用户认证 | 注册、登录 |
| 视频浏览 | 首页推荐、分类筛选 |
| 视频搜索 | 关键词、多条件筛选 |
| 视频播放 | 电影/剧集播放、进度记录 |
| 互动功能 | 评论评分、收藏 |
| 用户请求 | 请求添加新视频 |
| 个人中心 | 收藏、观看历史 |

### 后台管理模块

| 功能 | 说明 |
|------|------|
| 视频管理 | 增删改查 |
| 批量导入 | JSON文件导入 |
| 封面管理 | 自动获取、本地缓存 |
| 评论审核 | 审核评论、扣除积分 |
| 请求处理 | 处理用户请求 |
| 反馈管理 | 查看用户反馈 |
| 数据统计 | 视频/用户/评论统计 |

### 核心功能

- 📺 在线播放：支持电影和剧集
- 🎬 智能封面：多源获取、本地缓存
- ⭐ 个性推荐：基于用户偏好
- 💬 评论积分：评分评论、奖励机制
- 📝 请求添加：用户驱动内容扩展

## 使用方法

访问 https://mermaid.live 粘贴代码预览

## 1. 用户登录注册

```mermaid
flowchart TD
    A([访问系统]) --> B{已登录?}
    B -->|否| C[显示登录页]
    B -->|是| F[进入首页]
    C --> D[填写信息]
    D --> E{注册/登录}
    E -->|注册| G[创建用户]
    E -->|登录| H{验证}
    H -->|成功| F
    H -->|失败| C
    G --> F
```

---

## 2. 视频播放

```mermaid
flowchart TD
    A([点击视频]) --> B{视频类型}
    B -->|电影| C[显示播放按钮]
    B -->|剧集| D[显示集数列表]
    C --> E[初始化播放器]
    D --> E
    E --> F[播放视频]
    F --> G[每10秒保存进度]
    G --> H{用户离开?}
    H -->|是| I[保存最终进度]
    H -->|否| G
    I --> J([结束])
```

---

## 3. 封面获取存储

```mermaid
flowchart TD
    A([需要封面]) --> B{已有URL?}
    B -->|否| C[调用TMDB API]
    B -->|是| E[下载到本地]
    C --> D{成功?}
    D -->|否| C2[调用OMDB API]
    D -->|是| E
    C2 --> E
    E --> F[保存到covers/]
    F --> G[设置本地路径]
    G --> H([完成])
```

## 4. 个性化推荐

```mermaid
flowchart TD
    A([访问首页]) --> B{已登录?}
    B -->|否| C[显示热门视频]
    B -->|是| D[获取用户偏好]
    D --> E[获取候选视频]
    E --> F[计算推荐分数]
    F --> G[按分数排序]
    G --> H[取前8个]
    H --> I[显示推荐列表]
    I --> J{用户操作}
    J -->|换一批| F
    J -->|点击| K([进入详情])
    C --> K
```

---

## 5. 评论积分

```mermaid
flowchart TD
    A([发表评论]) --> B{已登录?}
    B -->|否| C[跳转登录]
    B -->|是| D[选择评分]
    D --> E[输入评论]
    E --> F[提交评论]
    F --> G{评论数≤2?}
    G -->|是| H[积分+2]
    G -->|否| I[不加分]
    H --> J([成功])
    I --> J
```

---

## 6. 批量导入

```mermaid
flowchart TD
    A([上传文件]) --> B[解析数据]
    B --> C[遍历视频]
    C --> D{标题为空?}
    D -->|是| E[跳过]
    D -->|否| F{已存在?}
    F -->|是| G[更新]
    F -->|否| H[创建]
    G --> I[获取封面]
    H --> I
    I --> J[下载到本地]
    J --> K[保存数据库]
    K --> L{还有?}
    L -->|是| C
    L -->|否| M([完成])
    E --> L
```

---

## 7. 请求添加视频

```mermaid
flowchart TD
    A([用户]) --> B[填写影片名]
    B --> C[提交请求]
    C --> D[状态: 待处理]
    D --> E([等待])

    F([管理员]) --> G[查看请求]
    G --> H{处理}
    H -->|添加| I[添加视频]
    H -->|忽略| J[标记忽略]
    I --> K[状态: 完成]
    J --> L[状态: 忽略]
```
