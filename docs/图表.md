## 5. 推荐算法流程图

```mermaid
flowchart TD
    Start[开始推荐] --> Input[输入用户ID]
    Input --> GetUser[获取用户信息]
    GetUser --> GetHistory[获取用户收藏历史]
    GetHistory --> FilterVideo[过滤已收藏视频]
    FilterVideo --> CalcScore[计算推荐分数]

    CalcScore --> BaseScore[基础分: 视频评分]
    CalcScore --> CategoryMatch[分类匹配: +10分]
    CalcScore --> RegionMatch[地区匹配: +8分]
    CalcScore --> LangMatch[语言匹配: +5分]
    CalcScore --> TypeMatch[类型匹配: +3分]
    CalcScore --> RandomScore[随机因子: 0-5分]

    BaseScore --> SumScore
    CategoryMatch --> SumScore
    RegionMatch --> SumScore
    LangMatch --> SumScore
    TypeMatch --> SumScore
    RandomScore --> SumScore[计算总分]

    SumScore --> Sort[降序排序]
    Sort --> Top8[取前8个]
    Top8 --> Return[返回推荐列表]

    style Start fill:#e8f5e9
    style Return fill:#e8f5e9
    style CalcScore fill:#fff9c4
    style Top8 fill:#ffccbc
```

## 如何查看这些图表

### 方式一：在线预览
1. 访问 [Mermaid Live Editor](https://mermaid.live/)
2. 将上述任意代码块复制粘贴进去
3. 即可看到渲染后的图表

### 方式二：本地编辑器
- **Typora**：原生支持 Mermaid，直接预览
- **VS Code**：安装 "Markdown Preview Mermaid Support" 插件
- **Obsidian**：原生支持

### 方式三：GitHub/GitLab
将此文件推送到 GitHub 或 GitLab，平台会自动渲染 Mermaid 图表
